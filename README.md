# 🏦 Персонализированные Push-уведомления для банка

## 📋 Описание

Высокоскоростной пайплайн для генерации персонализированных push-уведомлений для банковских продуктов на основе анализа поведения клиентов за последние 3 месяца.

**🚀 АСИНХРОННЫЙ LLM РЕЖИМ: Генерация через OpenAI GPT-4o-mini с 7x ускорением!**

## 🎯 Основные возможности

- **⚡ Асинхронная обработка** - 60 клиентов за 10-11 секунд (было 80 сек)
- **🤖 Чистая LLM генерация** - максимальное качество персонализации через OpenAI GPT-4o-mini
- **📊 Анализ поведения клиентов** - обработка транзакций и переводов за 3 месяца
- **🎯 Интеллектуальное ранжирование** - выбор оптимального продукта с учетом бизнес-правил
- **🔧 Модульная архитектура** - легко расширяемая и настраиваемая система

## 🏗️ Архитектура

```
[Данные] → [ETL] → [Features] → [Scoring] → [Ranking] → [AsyncLLM] → [Export]
    ↓         ↓         ↓           ↓          ↓         ↓          ↓
 CSV файлы  Загрузка  75 признаков  Выгода   Ранжирование  GPT-4o-mini  Результат
                                                        (10 сек/60 клиентов)
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск пайплайна

**Вариант 1: С API ключом через аргумент (рекомендуется)**
```bash
python src/pipeline.py data/clients.csv --api-key your_openai_api_key_here
```

**Вариант 2: Через .env файл**
```bash
# Создайте файл .env с вашим OpenAI API ключом
echo "OPENAI_API_KEY=your_openai_api_key_here" > .env

# Запустите пайплайн
python src/pipeline.py data/clients.csv
```

**🔑 Где получить API ключ:** https://platform.openai.com/api-keys

## 🏆 Поддерживаемые продукты

1. **Карта для путешествий** - 4% кешбэк на путешествия и такси
2. **Премиальная карта** - до 4% кешбэк в зависимости от депозита
3. **Кредитная карта** - до 10% в любимых категориях (лимит 30 000 ₸/мес)
4. **Депозит Мультивалютный** - 14,5% для FX-активных клиентов
5. **Депозит Сберегательный** - 16,5% без снятия
6. **Депозит Накопительный** - 15,5% с пополнением
7. **Обмен валют** - выгодный курс без комиссии 24/7
8. **Инвестиции** - 0% комиссии на старт, от 6₸
9. **Золотые слитки** - диверсификация для VIP клиентов
10. **Кредит наличными** - от 12% годовых без залога

## 🤖 LLM Особенности

### Качество генерации:
- ✅ **100% консистентность** продукт ↔ текст
- ✅ **Персонализированная лаконичность** - уникальные push для каждого клиента
- ✅ **Соблюдение TOV** - 180-220 символов, макс 1 "!", без КАПСА
- ✅ **Реалистичные обещания** - без "0 ₸", с учетом лимитов
- ✅ **Временная консистентность** - единообразно "за последние 3 месяца"

### Технические характеристики:
- 🚀 **AsyncOpenAI** - параллельная обработка до 10 запросов
- 📈 **Умное кэширование** - избегание дублирующих запросов
- ⚡ **Семафор контроль** - оптимальная нагрузка на API
- 🔄 **Автоисправление** - консистентность продуктов и текста
