# 🏦 Персонализированные Push-уведомления для банка

## 📋 Описание

Интеллектуальный пайплайн для генерации персонализированных push-уведомлений для банковских продуктов на основе анализа поведения клиентов за последние 3 месяца.

**🤖 ЧИСТЫЙ LLM РЕЖИМ: Генерация через OpenAI GPT-4o-mini с 95%+ качеством персонализации!**

## 🎯 Основные возможности

- **Анализ поведения клиентов** - обработка транзакций и переводов за 3 месяца
- **Расчет выгоды продуктов** - математические модели для каждого банковского продукта  
- **Интеллектуальное ранжирование** - выбор оптимального продукта с учетом бизнес-правил
- **Чистая LLM генерация** - максимальное качество персонализации через OpenAI GPT-4o-mini
- **Модульная архитектура** - легко расширяемая и настраиваемая система

## 🏗️ Архитектура

```
[Данные] → [ETL] → [Features] → [Scoring] → [Ranking] → [LLM] → [Export]
    ↓         ↓         ↓           ↓          ↓        ↓       ↓
 CSV файлы  Загрузка  Признаки   Выгода   Ранжирование  GPT-4o  Результат
                                                       (макс качество)
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка OpenAI API (ОБЯЗАТЕЛЬНО)

```bash
# Создайте файл .env с вашим OpenAI API ключом
echo "OPENAI_API_KEY=your_openai_api_key_here" > .env
```

**🔑 Где получить API ключ:** https://platform.openai.com/api-keys

**⚠️ Важно:** Без API ключа система не запустится!

### 3. Запуск пайплайна

```bash
python src/pipeline.py data/clients.csv
```

**🤖 LLM характеристики:**
- 🎯 Скорость: 5-10 секунд
- 🏆 Качество: 95%+ персонализация
- 🤖 Надежность: Чистый LLM режим
- 💰 Стоимость: ~$0.01-0.02/клиент

### 4. Результат

Результаты сохраняются в `output/recommendations.csv`:

```csv
client_code,product,push_notification
1,Кредитная карта,"Айгерим, ваши топ-категории — продукты, рестораны, такси. Кредитка вернула бы 67 400 ₸ кешбэком за 3 месяца. Плюс беспроцентный период до 62 дней. Оформить карту."
2,Премиальная карта,"Данияр, вы часто в ресторанах и бутиках (42 500 ₸/мес). Премиальная карта вернёт 4% с этих трат плюс бесплатные снятия по миру. Оформить сейчас."
```

## 🏆 Поддерживаемые продукты

1. **Карта для путешествий** - 4% кешбэк на путешествия и такси
2. **Премиальная карта** - 2-4% кешбэк в зависимости от депозита
3. **Кредитная карта** - до 10% в любимых категориях
4. **Обмен валют** - выгодный курс без комиссии
5. **Кредит наличными** - от 12% годовых без залога
6. **Депозит Мультивалютный** - 14,5% с доступом к средствам
7. **Депозит Сберегательный** - 16,5% без снятия
8. **Депозит Накопительный** - 15,5% с пополнением
9. **Инвестиции** - 0% комиссии, от 6₸
10. **Золотые слитки** - диверсификация портфеля

## ⚙️ Конфигурация

### Настройка весов (`conf/weights.yaml`)

```yaml
travel_card:
  cashback_rate: 0.04
  monthly_limit: 30000
  categories: ["Путешествия", "Такси", "Отели"]

premium_card:
  base_rate_by_deposit:
    tier1: 0.02  # < 1M
    tier2: 0.03  # 1-6M  
    tier3: 0.04  # > 6M
```

### 🤖 Настройка LLM промптов (`conf/llm_prompts.yaml`)

```yaml
system_prompt: |
  Ты - эксперт по персонализированным банковским уведомлениям...
  
product_prompts:
  travel_card: |
    Создай push для карты путешествий...
```
