# 🚀 Персонализированные Push-уведомления для Банковских Продуктов

Пайплайн для генерации персонализированных push-уведомлений на основе транзакционных данных клиентов банка.

## 🤖 **НОВОЕ: LLM Генерация Push-уведомлений**

Добавлена возможность генерации push-уведомлений через OpenAI GPT для максимальной персонализации и соблюдения строгих требований TOV из ТЗ хакатона!

## 📋 Описание

Система анализирует транзакции клиентов за последние 3 месяца и предлагает наиболее подходящие банковские продукты с персонализированными push-уведомлениями. 

### Поддерживаемые продукты:
- 💳 Карта для путешествий (4% кешбэк)
- 👑 Премиальная карта (до 4% кешбэк + привилегии)
- 💰 Кредитная карта (10% кешбэк на топ категории)
- 💱 Валютный счет
- 💵 Кредит наличными
- 📈 Депозиты (мультивалютный, сберегательный, накопительный)
- 📊 Инвестиции
- 🏆 Золото

## 📊 Формат входных данных

CSV файл со следующими колонками:
- `client_code` - уникальный ID клиента
- `name` - имя клиента
- `status` - статус (Студент/Зарплатный клиент/Премиальный клиент/Стандартный клиент)
- `age` - возраст
- `city` - город
- `avg_monthly_balance_KZT` - средний месячный баланс
- `date` - дата транзакции (YYYY-MM-DD)
- `category` - категория траты
- `amount` - сумма
- `currency` - валюта (KZT/USD/EUR)
- `type` - тип транзакции
- `direction` - направление (in/out)

## 🔧 Параметры командной строки


## 📈 Алгоритм работы

1. **ETL**: Загрузка данных, конвертация валют, фильтрация за 3 месяца
2. **Feature Engineering**: Расчет 50+ агрегированных признаков
3. **Scoring**: Расчет benefit score для каждого продукта
4. **Ranking**: Выбор топ-4 продуктов по benefit и приоритету
5. **Compose**: Генерация персонализированных push-уведомлений
6. **Export**: Сохранение результатов в CSV/Excel

## 📝 Правила push-уведомлений

- ✅ Максимум 220 символов
- ✅ Без CAPS LOCK
- ✅ Максимум один "!"
- ✅ CTA: Открыть/Настроить/Посмотреть
- ✅ Формат валюты: "2 490 ₸"

## 🔍 Детали реализации

### Benefit Score формулы:

- **Travel Card**: `0.04 * (Путешествия + Такси + Отели)`, cap 100k
- **Premium Card**: `tier_cashback * total + 0.04 * special + saved_fees`
- **Credit Card**: `0.1 * top3_categories + 0.1 * online`, при наличии кредитной активности
- **FX**: `0.01 * fx_volume`
- **Cash Loan**: `0.1 * (outflows - inflows)`, если outflows ≥ 1.5×inflows
- **Deposits**: различные ставки 14.5-16.5% годовых
- **Investments**: `0.01 * balance`, если free_funds > 100k
- **Gold**: `0.005 * balance`, при наличии трат на ювелирку
